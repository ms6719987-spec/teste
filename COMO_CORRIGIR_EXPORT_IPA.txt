CORRECAO DO ERRO export_options.plist

O arquivo export_options.plist foi adicionado na raiz do projeto.

Se o seu compilador estiver configurado para:
  /Users/builder/export_options.plist
voce DEVE alterar essa configuracao para o caminho real do arquivo apos extrair o ZIP.

Exemplo: se o repositorio foi clonado para /Users/builder/clone/3105-2.0,
use /Users/builder/clone/3105-2.0/export_options.plist.

Alternativamente, no passo de script anterior ao build, copie o arquivo:
  cp "$CM_BUILD_DIR/export_options.plist" /Users/builder/export_options.plist
(apenas se CM_BUILD_DIR apontar para a raiz correta do projeto).

O metodo ad-hoc requer assinatura e perfis de provisionamento validos.
Se o seu objetivo for outro tipo de distribuicao, altere o metodo e a assinatura.
